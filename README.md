# C Number Guessing Game 🎮

A simple number guessing game developed using the C programming language.

## About the Project
The computer generates a random number between 1 and 1000. The player has to guess the correct number.

The game provides hints:
- Guess a higher number.
- Guess a lower number.
- Displays the total number of guesses.

## Concepts Used
- C Programming
- Variables and Data Types
- If-Else Statements
- Do-While Loop
- Random Number Generation
- User Input and Output

## How to Run

Compile:
```bash
gcc main.c -o game
```

Run:
```bash
./game
```
